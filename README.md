Employee Attrition Prediction
Problem Statement

Employee attrition can negatively impact business productivity and increase hiring costs. This project predicts whether an employee is likely to leave the company using machine learning techniques.

Dataset

A synthetic dataset was created for educational purposes.

Features used:

Age
Department
Salary
Years At Company
Overtime Hours
Work Satisfaction
Distance From Home
Promotion Last 2 Years

Target variable:

Attrition (0 = Stay, 1 = Leave)
Project Workflow
Data Collection and Exploration
Data Cleaning and Preprocessing
Feature Engineering
Model Selection
Model Evaluation
Cross Validation
Visualization and Insights
Models Used
Logistic Regression

Accuracy: 82.86%

Decision Tree

Accuracy: 98.57%

Key Findings
Low work satisfaction increases attrition.
Higher salaries reduce attrition.
Excessive overtime contributes to attrition.
Employees with fewer promotions are more likely to leave.
